# Security Policy

## Supported Versions

Only the latest version on `main` is supported. That is the version on the live site. Security fixes go to `main` and deploy from there.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

[Report vulnerabilities privately](https://github.com/aeskildsen/flux/security/advisories/new). Include:

- Steps to reproduce
- Affected versions
- Potential impact

This project is maintained on a best-efforts basis. There are no guaranteed response times for security reports.
